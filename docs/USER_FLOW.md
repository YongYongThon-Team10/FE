# 백엔드 없이 확인하는 전체 서비스 흐름

`VITE_API_BASE_URL`을 비우고 `npm run dev`를 실행하면 시연 데이터로 아래 여정을 완주할 수 있다. 백엔드는 별도 담당자가 개발하며, 실제 API가 준비되면 서비스 어댑터를 맞춘다. 백엔드 구현이나 병합을 이 작업의 전제로 두지 않는다.

| 단계    | 사용자 행동                                    | 이어지는 상태                                   |
| ------- | ---------------------------------------------- | ----------------------------------------------- |
| 진입    | `#/onboarding` → 시작하기 → 게스트로 입장      | 로그인 없이 홈 진입                             |
| S1 검색 | ‘이번 주말 기흥구 아이와 야외’ 입력 → 검색     | 조건 해석 결과를 칩으로 확인·수정               |
| S2 탐색 | 조건으로 검색 → 목록/지도 전환                 | 같은 필터의 행사 결과와 마커                    |
| S3 상세 | 마커 미리보기 → 행사 선택                      | 선택 행사·프로그램·요금·출처·신청 안내          |
| S4 설정 | 이 행사로 하루 짜기 → 아이 나이·출발지 등 입력 | 검색의 날짜·동행·무료 조건 이어받기             |
| S5 일정 | 일정 만들기                                    | 행사·프로그램·식사·근처 행사·귀가 5칸           |
| 편집    | 장소 교체·직접 입력·추가·삭제·순서 변경        | 시간표와 지도 방문 순서 재계산                  |
| 동선    | 지도에서 동선 확인 → 장소/마커 선택            | 주소·운영·요금·갱신 출처 카드                   |
| 보관    | 뒤로 → 저장·공유 → 내 코스에 저장              | 편집한 상태로 브라우저에 보관                   |
| 공유    | 공유 링크 생성 → 다른 브라우저에서 열기        | 출발지·현재 좌표·아이 나이를 제외한 일정 스냅샷 |
| 재방문  | 내 코스 → 코스 열기 → 조건 바꾸기              | 편집/재생성으로 다시 연결                       |

위의 주말 입력은 접속한 날짜 기준으로 해석한다. Figma 예제 행사는 2026-11-14~15로 고정되어 있으므로 다른 주에 확인할 때는 칩에서 그 날짜를 고르거나 행사명으로 검색한다. 자동 테스트는 2026-11-12 서울 시간에 고정한다.

후보 없음·무료 조건 불일치·위치 권한 거부·지도 배경 실패·저장 공간 부족·공유 링크 오류도 각각 다음 행동을 안내한다. 좌표가 없는 장소와 확인되지 않은 가격은 실제값을 지어내서 채우지 않는다.

`tests/journey.spec.ts`는 위 여정을 실제 버튼 클릭으로 한 번에 검증한다. `tests/service.spec.ts`는 예외·저장·공유·반응형 동작을, `tests/remote.spec.ts`는 백엔드 대체 응답으로 갱신·실패·복구를 검증한다. 실제 계정 인증·문의 접수·AI 호출·데이터 수집 작업은 서버 연결 이후 확인한다.
